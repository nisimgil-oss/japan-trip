## ⚠️ מקור-אמת יחיד
הגרסה הקנונית היא ה-repo (branch `main`) והאתר החי. **אין להריץ את `_build.js`** שנמצא בעותק המקומי — הוא בונה `data.js` מ-`_trip_en.json` (גרסה ישנה) ועלול לדרוס את מסלול אופציה A. לעריכות תוכן — עורכים ישירות את `data.js`, או מסנכרנים מה-repo.
